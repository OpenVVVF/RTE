# Assets

Drop a logo file here to have it overlaid on every figure.

- Expected default path: `Tools/rteplot/assets/logo.png`
- Supported formats: PNG, JPG, SVG (anything Plotly layout images accept)
- You can also pass a custom logo with `--logo path/to/logo.png`

A tasteful size is roughly 200–300 px wide with a transparent background.
The logo is placed in the top-right corner of each figure.
